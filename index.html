簡単スライム化キット
β テスター資料

アバターに prefab を 1 つ置いて設定するだけで、メニューから「スライム化」できるキットです。この資料では、参加の要項と、設定画面の見方を画面のスクショで説明します。

このツールはベータ版です。

Claude (AI) を利用して開発しているため、AI に抵抗がある方には申し訳ありませんが、辞退をお願いします。

このキットについて

β の目的は、いろいろなアバターで設定だけで正しく動くかを確かめることです。

  • スライム化すると、胸のコアから半透明のゼリーの体に変わり、垂れ・水たまり・コアが出ます
  • メニューで色・光る・垂れ・水たまりを切り替えられます。「スライムの時は溶けて消える」にした服は、スライムになって溶け落ちます
  • 元のアバターは書き換えません。アップロードの時にだけスライム化の処理が入ります (非破壊)
  • PC 専用 (自作シェーダーのため Quest 非対応)

要項

下の条件と「分かっている制限」を確かめてから参加してください。

項目条件

環境PC で VRChat を遊んでいる (デスクトップでも VR でも可)

申請は要りません。サーバーに参加した時点でテストへの参加として受け付けます。

1

導入の手順

  1. テスト用のプロジェクトを作る

    普段使っているプロジェクトには入れないでください。アバター用プロジェクトを丸ごと複製しても構いません。

  2. 複製したプロジェクトに unitypackage をインポートする

    Assets/LeachiToyBox/EasySlime ができます。

  3. テスト用にアバターを複製し、blueprint ID を外す

    普段使いのアバターとは別の ID で、新しくアップロードします。

  4. EasySlime.prefab をアバターのルートの子に置く

    シーンのアバターの見た目は変わりません。設定用の部品 (Easy Slime Avatar) が置かれるだけです。

  5. prefab のインスペクターで設定する

    「準備」を上から ✔ にして、必要なら「好み」を選びます。画面の見方は 2 章から。

  6. SDK からプライベートでアップロードする

    スライム化の処理はアップロードの時に、ビルド用の複製にだけかかります。

  7. ゲーム内で Expression メニューの「スライム」を開いて試す

やめる時は prefab を消すだけです。

2

設定画面の全体

prefab を選ぶと、インスペクターに Easy Slime Avatar が出ます。上から 準備・好み・細かく調整 の 3 段です。ふつうは準備と好みだけで足ります。

準備

上から順に ✔ にするチェックリスト。✔ は緑、要確認は黄色の「!」、足りない時は赤の「✖」。全部 ✔ ならそのままアップロードできます。

好み

色・雰囲気・重さ・コア・メニューの初期値。見た目の方向をまとめて決めます。既定のままでも動きます。

細かく調整

好みで決めた中身を 1 項目ずつ変える所。項目にマウスを乗せると説明が出ます。

3

4

顔マスクの選び方

顔マスクは、目・まつげ・眉・口など元の絵のまま残す部品を決めるものです。どのアバターも最初に自分で選びます。選ぶまでは、顔は元の絵のまま (スライムになりません)。

  1. 「マスク選択の画面を開く」を押す

    初めて開いた時は「おまかせ」(推測) で選ばれた状態から始まります。

  2. 部品をクリックして直す

    クリックで赤くなり、もう一度で戻ります。赤 = 元の絵のまま残る、赤くない所 = スライムになる、暗い所は顔に使われていない所です。マウスを乗せた部品は黄色く光ります。

    • 島になっていないチーク・線は、上の「塗りつぶし」に切り替えて塗ります
    • 間違えたら「1 つ前に戻す (Ctrl+Z)」、やり直すなら「おまかせで選ぶ」

  3. 「保存してこのマスクを使う」

    Generated/<アバター名>/FacePickMask.png に保存されます。次に開くと続きから直せます。

自分で作った白黒の画像を使う場合は、③ の「顔マスク」の欄で「自分で作ったマスク画像を使う」を選びます。

送ってほしいもの
  • マスク選択の画面の、開いた直後 (おまかせのまま) のスクショ
  • 直して保存した後のスクショ、または FacePickMask.png
  • ゲーム内でスライムにした時の顔のスクショ (正面と斜め)

おまかせの外れ方を集めて、推測を直すのに使います。顔のテクスチャそのものは送らなくて大丈夫です。

細かく調整

8 つのまとまりに分かれています。どれも既定のままで動きます。気になる所だけ変えてください。

体

項目既定説明
体の崩れ1体がどれだけ形を崩して、だれたり膨らんだりするか。0 = 形そのまま / 1 = 標準 / 2 = もっと崩れる
細くなる上限 (cm)0.4崩れで体が元より細くなる量の上限。腕・指が棒のように細くなる時は小さく
服・小物の崩れ1② でスライムにした服・小物の崩れ方。小物はさらに控えめ
溶けて垂れる量0.7体の表面がどれだけ溶けて下へ垂れるか。0 = 垂れない / 1 = たくさん

垂れと水たまり

項目既定説明
体から落ちる垂れオン体の下向きの所から液が垂れて床まで落ちる。オフにすると作らない (ゲーム内メニューの「垂れ」は作った垂れを出し入れする)。本数 (既定 600、多いほどポリゴンも増える) と太さ (1.35 が標準)
体を伝って流れ続ける筋オン体の表面を、液の筋がゆっくり流れ落ち続ける
服の上の垂れが流れ続けるオン「服 (上にも垂れる)」の服の上の垂れ。オン = 流れ落ち続ける / オフ = 伸びたら止まる
足元の水たまりオンスライムになると足元に水たまりが広がる。ゲーム内メニューでもオンオフできます
髪の先から垂れるなしなし = 髪そのものが溶けたように見える / あり = 毛先が膨らんで、ちぎれた雫が床へ落ちる

顔と髪

項目既定説明
顔はスライムにしないオフオン = 顔は元の絵のまま (首から下だけスライム)。顔マスクも要らなくなります
頭を透かさないオフオン = 頭の向こうが透けず、首から顎へ少しずつ透けなくなる。頭の中の物が見える時に
顔も揺らす (試験中)オフ顔も体と一緒にぷるぷる揺れる。唇が動いて歯が見えることがあります
髪の崩れ00 = 髪の形はそのままで質感だけスライム。上げると髪も垂れて崩れます (前髪の長いアバターは目が隠れることがあります)
髪の奥を透かすオン髪がガラスのように透けて、奥の頭や体が見える。オフ = 髪は一様な色
体の後ろの髪も透かすオフオン = 前から見て、体の後ろの髪が体越しに透ける (胴の色が濃くなりやすい)

中の泡と、近づいた時

項目既定説明
中の泡 / 泡の量オン / 0.12スライムの中に小さな泡が浮かんで、ゆっくり昇る。0 = なし、上げるほど泡だらけ
近づくとスライムの中の景色になるオン見ている人のカメラが体に近づくと濃くなり、体の中に入ると視界がスライムで埋まる (泡・揺らめき・歪んだ外)
中の濃さ0.50 = 外がよく見える / 0.5 = 標準 / 1 = ほとんど外が見えず、締め付けて脈打つ
沈み込んだ所がべちゃっとなるオンほかの人の体や床がスライムに沈んだ境目に、濃い液の縁とつやを出す。影の出るワールドだけで見えます

項目既定説明
色ピンクコアの色
外側の濃さ0.3コアのまわりの薄い膜の濃さ。0 = 芯だけ / 1 = 外側まで濃い

触ったときの反応

項目既定説明
反応する場所の数6手・指・足・頭が触れると、へこんで盛り上がり波紋が広がる場所の数 (お腹・股・胸・お尻・太もも左右)。多いほど VRChat の Contacts を使います
相手の体が入るとへこむオンお腹・胸・お尻に相手の体が入ると、その分へこむ (Contacts +3)

軽くする (見た目が少し変わる)

項目既定説明
透け方の計算をまとめるオフ髪・垂れ・水たまりの透け方を 1 回の計算にまとめて軽くする。体は透けるが、奥の髪や垂れどうしは透けなくなる
服の上の垂れ・小物を簡易表示にするオフ厚みを測らずに描く回数を減らす。少し平たく見える
髪の裏側を描かないオフ髪の裏面を描かずに軽くする。板の髪を裏から見ると消える

上級者向け (ふつうは触らなくて大丈夫)

  • 垂れの形: 落ちる垂れの形 (細い筋 / 雫)、先の膨らみ、ちぎれた雫の大きさ、落ちる速さ、体を伝う筋の太さ、体の表面を流れるつや、服の上の垂れの太さ・速さ
  • 泡: 泡の大きさ (0.5 が標準)、泡が昇る速さ (cm/秒)
  • 顔の厚み: 顔も本当の厚みで透ける (目のまわりに枠のような濃い線が出る時はオフ)、顔の厚みの下限
  • 体の部位ごと: 手・腕・胴・胸・脚・足ごとに、溶け (溶ける強さ)・上限 (元の形からどこまで膨らむか cm)・垂れ (落ちる垂れの量)
  • その他: ポリゴン量を「重さ」より細かく選ぶ、糸 (腕と胴など近い所どうしを液の糸で結ぶ)

困ったときの設定

こうなったらここを変える
服の下からスライムが漏れる② の「服の下とみなす距離」を上げる
顔がスライムにならない③ の顔マスクを選んで保存したか確かめる。① の「顔の肌の材質」が合っているか

前髪が目にかかる顔と髪の「髪の崩れ」を下げる (0 なら髪の形はそのまま)

目のまわりに枠のような濃い線が出る上級者向けの「顔も本当の厚みで透ける」をオフ、または「顔の厚みの下限」を上げる

形がドロドロすぎる / 物足りない好みの「雰囲気」を控えめ・ドロドロに

確認してほしいこと

一番知りたいのは「設定だけで最後まで通るか」と「ゲーム内で崩れて見える所がないか」です。全部でなくて構いません。試せた所だけ報告してください。

導入
  • prefab を入れて、エラーなくアップロードできた (コンソールに赤いエラーが出たらその内容も)
  • ① 体・顔のメッシュが自動で正しく入った
  • ② 髪・服の振り分けのおすすめが合っていた
  • ③ 顔マスクの「おまかせ」が合っていた / どこを直したか
  • ④ プレビューで見た目を確かめられた
普段の見た目
  • アップロード後も、元のアバターと同じ見た目だった (他の人から見ても)
スライム化
  • 胸のあたりから広がって、全身がスライムになった
  • 顔: 目・眉・口が残り、肌がスライムになった。顔の中の部品が透けていない
  • 表情 (赤面・涙など) を出しても崩れない
  • 髪・服が設定どおり
  • 「溶けて消える」にした服が、スライムになって溶け落ちた
  • 垂れ・水たまりが床の高さに合っている (座り・寝そべりも)
  • 解除したら元の見た目に戻った
メニュー
  • 色 / 光る のラジアルが効く
  • 垂れ・水たまりのオンオフ
  • 触るとへこむ (自分や他の人の手で)
ゲーム内の環境
  • 明るいワールド・暗いワールドそれぞれでの見え方 (ワールド名も)
  • ミラー・カメラでの見え方
  • 重さ: パフォーマンスランク、スライム化した時の FPS の落ち方
他のツールとの干渉
  • 入れているギミック (表情・衣装の切り替えなど) が今までどおり動く
  • TexTransTool のメイク、AAO の最適化と一緒に使える

回答と不具合の報告

回答の書式

下の書式をコピーして Discord サーバーで送ってください。一言でも構いません。

【アバター】
【入れているツール】(AAO / TexTransTool / FaceEmo など)
【1. 質感・表現】良かった所・物足りない所
【2. 重さ】パフォーマンスランク、スライム化した時の FPS、「重さ」を変えた前後
【3. 顔マスク】おまかせはどれくらい合っていたか、どこを直したか (スクショ)
【4. 出来ると嬉しいこと】
【5. 分かりづらかった設定】
【6. ゲーム内のメニューで変えたいもの】
【7. 不具合】(別に送ったものは「送信済み」で OK)

不具合の報告

気付いた時点で 1 件ずつ送ってください。スクショや短い動画があると原因を見つけやすくなります。「こうだったらいいのに」という要望や、動いたという報告だけでも助かります。

分かっている制限

次の点は把握しています。報告は不要ですが、「ここが特に気になる」という声は歓迎です。

制限内容
PC 専用Quest・スマホからはフォールバックの見た目になります
ゲーム内のシェイプキー胸の大きさなどをゲーム内で変える機能には対応していません。垂れ・服の上の垂れはアップロードした時の体型で作られます
T ポーズ前提アバターの初期姿勢が T ポーズでないと、垂れの位置がずれることがあります
lilToon 前提元の材質から写す値は lilToon のもの。ほかのシェーダーはテクスチャと色だけです
体と顔が 1 つのメッシュ対応しましたが、実際の一体型アバターではまだ確かめていません。お持ちの方はぜひ
大きい服の垂れT シャツなどは、垂れが肌に接した縁からしか湧かず、本数が少なめです (調整中)
暗いワールド垂れの先・縁が明るく浮いて見えることがあります
頭の中表面のすぐ内側では、表情の板がうっすら見えることがあります
